# Docker Image Size Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce each production service image from 348-367 MB to 250 MB or less while preserving application behavior, pinned Node runtime, non-root execution, and the current NestJS/webpack architecture.

**Architecture:** Keep four service-specific Dockerfiles and compile `libs/common` into each webpack bundle. Make every app a pnpm workspace package with a complete production dependency manifest, keep shared packages at the root only as build/test `devDependencies`, enable injected workspace packages, and use `pnpm --filter <app> --prod deploy` in an intermediate deployment stage. Production stages copy only the selected bundle, deployed package metadata, and deployed `node_modules`.

**Tech Stack:** Node.js 24 Alpine (digest pinned), pnpm 11.5.0 workspaces, NestJS 11, webpack, Docker BuildKit

---

## Spec Alignment Notes

The approved design is sound, with these repo-specific corrections incorporated
into this plan:

1. `apps/reservations/package.json` does not exist. The documented
   `@hotel-booking/reservations` filter currently matches no project, so the
   implementation must create that workspace manifest before filtered deploy can
   work.
2. `libs/common` is compiled from root source and is not a workspace package.
   Shared runtime libraries therefore cannot disappear from the root manifest
   entirely: move them from root `dependencies` to root `devDependencies` for
   build/test resolution, while duplicating each service's required production
   set in its app manifest. Filtered `--prod deploy` excludes root
   `devDependencies`.
3. pnpm 11's modern deploy implementation requires
   `injectWorkspacePackages: true`. Add it to `pnpm-workspace.yaml` before
   regenerating the lockfile so deploy can derive service-specific lockfiles.
4. Static `require("...")` extraction does not see dynamic loading such as the
   configured `pino-pretty` transport or Nest's default platform adapter.
   Bundle extraction remains a useful check, but deployment resolution and real
   container bootstrap are required gates.
5. Baseline images were verified on June 12, 2026:
   `reservations=348MB`, `auth=352MB`, `payments=367MB`, and
   `notifications=349MB`.

Run:

```bash
rtk node - <<'NODE'
const fs = require('node:fs');
const { builtinModules, createRequire } = require('node:module');

const builtins = new Set([
  ...builtinModules,
  ...builtinModules.map((name) => `node:${name}`),
]);
const dynamicRuntimePackages = [
  '@nestjs/platform-express',
  'pino',
  'pino-http',
  'pino-pretty',
  'reflect-metadata',
];

for (const service of ['reservations', 'auth', 'payments', 'notifications']) {
  const target = `/tmp/hotel-booking-deploy-${service}`;
  const bundle = fs.readFileSync(`dist/apps/${service}/main.js`, 'utf8');
  const deployedPackage = JSON.parse(
    fs.readFileSync(`${target}/package.json`, 'utf8'),
  );
  if (deployedPackage.name !== `@hotel-booking/${service}`) {
    throw new Error(`${service}: wrong deployed package metadata`);
  }

  const deployedWorkspaceScope = `${target}/node_modules/@hotel-booking`;
  if (
    fs.existsSync(deployedWorkspaceScope) &&
    fs.readdirSync(deployedWorkspaceScope).length > 0
  ) {
    throw new Error(`${service}: unrelated workspace package was deployed`);
  }

  const runtimePackages = new Set(dynamicRuntimePackages);

  for (const match of bundle.matchAll(/require\("([^"]+)"\)/g)) {
    const dependency = match[1];
    if (builtins.has(dependency)) continue;
    runtimePackages.add(
      dependency.startsWith('@')
        ? dependency.split('/').slice(0, 2).join('/')
        : dependency.split('/')[0],
    );
  }

  const resolveFromDeployment = createRequire(`${target}/package.json`);
  for (const dependency of runtimePackages) {
    resolveFromDeployment.resolve(dependency);
  }

  console.log(`${service}: ${runtimePackages.size} runtime packages resolve`);
}
NODE
```

const http = require('node:http');

async function waitForHealth(port) {
  for (let attempt = 0; attempt < 30; attempt += 1) {
    try {
      const body = await new Promise((resolve, reject) => {
        const request = http.get(
          { hostname: '127.0.0.1', port, path: '/', timeout: 1000 },
          (response) => {
            let data = '';
            response.setEncoding('utf8');
            response.on('data', (chunk) => {
              data += chunk;
            });
            response.on('end', () => {
              if (response.statusCode !== 200) {
                reject(new Error(`HTTP ${response.statusCode}`));
                return;
              }
              resolve(data);
            });
          },
        );
        request.on('timeout', () => request.destroy(new Error('timeout')));
        request.on('error', reject);
      });

      if (body.trim() !== 'true') {
        throw new Error(`unexpected body: ${body}`);
      }
      return;
    } catch {
      await sleep(1000);
    }
  }

  throw new Error(`health endpoint on port ${port} did not become ready`);
}
